# Tomorrow Marketers — Case Lab

## Project
A lightweight, Vietnamese-language, student-facing interactive case-study worksheet for in-class exercises. Vanilla HTML/CSS/JavaScript in `index.html`. No build dependencies; open `index.html` directly in a browser.

## Non-negotiable content constraints
- Preserve all five existing cases and their slide-derived wording, questions, table columns and numbers EXACTLY as in the currently approved version. Do not add, remove, paraphrase, correct or invent case questions, data or totals without explicit user approval.
- Do not add automatic media-spend reallocation, KPI projections, simulated performance, or budget-optimization controls.
- Keep the student UI free of instructor/internal annotations: no 'slide gốc', 'data gốc', discrepancy/QA/source notes in the visible app.
- Student response method: type directly into the existing answer fields only. Do not add download/export, copy, clear/delete or submit buttons unless explicitly requested.
- Preserve lightweight table exploration (search/sort) and local browser draft persistence if it exists.
- UI style: clean, compact, Vietnamese-first, Tomorrow Marketers pink accent.
- If data appear internally inconsistent, report the concern to the project owner separately instead of silently altering slide-derived values.

## Working guidance
- Make minimal, targeted changes. Keep it usable within a 10–15-minute classroom exercise.
- Avoid external services and dependencies unless specifically asked.
- Test changes by opening `index.html` in a browser.
